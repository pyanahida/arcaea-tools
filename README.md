# Arcaea Tools

Arcaea 玩家向的小工具集合，纯静态页面，无需构建、无需后端，直接打开即用。

当前包含：

- **谱面长图**：把 `.aff` 谱面渲染成一条纵向长图，用于快速预览整张谱面的密度与走向

## 快速开始

```bash
# 克隆后直接打开
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

也可以用任意静态服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

> 直接双击 `index.html` 以 `file://` 协议打开也可正常工作，本工具不请求任何外部资源。

## 目录结构

```
arcaea-tools/
├── index.html      # 主页，工具入口
├── chart.html      # 谱面长图页面
├── chart.css       # 长图专用样式（SVG 满宽与纵向翻转）

```

## 谱面长图

### 使用方法

1. 从主页进入「谱面长图」
2. 点击文件框，选择 `0.aff` 至 `4.aff` 中的任意一个
3. 在缩放框填入数值（建议 30–150，默认 80）
4. 点击「解析并绘制」，滚动查看长图

### 支持范围

| 物件 | 状态 |
|---|---|
| 地面 Tap | 已支持，方块 |
| 地面 Hold | 已支持，竖条 |
| Timing | 已支持，小节线 |
| Arc / ArcTap | 未支持，忽略 |
| Camera / SceneControl | 未支持，忽略 |

未支持的物件会被静默忽略，不报错也不渲染。

### 缩放说明

缩放框的数值是百分比，`80` 表示 0.8 倍。画布高度会按 `谱面最大时间 × 缩放系数` 生成，因此：

- 填小值（如 50）→ 图更矮更密，适合整曲概览
- 填大值（如 150）→ 图更高更疏，适合局部细看

### 已知限制

- 谱面开头位于页面底部（`scaleY(-1)` 翻转），需滚动到底
- 变速或变拍号的谱面，小节线间距仅按首段推算
- 未支持导出为图片

## 开发

纯 HTML + CSS + JS，无依赖、无构建步骤。修改后刷新浏览器即可看到效果。

调试建议：解析异常目前被外层 `try/catch` 静默捕获，排查问题时可临时把 `catch (e) { console.log(e); }` 改为 `alert(e.message)`，让错误直接显示出来。
